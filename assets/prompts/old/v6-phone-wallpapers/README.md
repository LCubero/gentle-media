# Fondos verticales v6

Siete prompts independientes para fondos individuales y composiciones combinadas. No se incluyen imágenes ni logotipos: los archivos transparentes auténticos se adjuntarán posteriormente.

| Composición | Prompt | Adjuntos necesarios |
| --- | --- | --- |
| Gentleman Programming | `GENTLEMAN.md` | 1 logotipo de Gentleman Programming |
| Gentle-AI | `GENTLE-AI.md` | 1 logotipo de Gentle-AI |
| Engram | `ENGRAM.md` | 1 logotipo de Engram |
| gentle-shell | `GENTLE-SHELL.md` | 1 logotipo de gentle-shell |
| Gentle-AI + gentle-shell | `GENTLE-AI-GENTLE-SHELL.md` | 2 logotipos: uno por marca |
| Gentle-AI + Engram | `GENTLE-AI-ENGRAM.md` | 2 logotipos: uno por marca |
| Las cuatro marcas | `ECOSYSTEM.md` | 4 logotipos: uno por marca |

Abra un archivo, copie su texto completo en el generador y adjunte únicamente los logotipos transparentes auténticos que solicita ese prompt. Repita por separado para cada composición. Los vínculos entre marcas son ejemplos ilustrativos, no integraciones obligatorias. ODD, RDD y código son conceptos, no marcas adicionales.

Revise cada resultado a escala de teléfono y en el dispositivo previsto: legibilidad, nombres exactos, integridad de los logotipos, zonas de reloj e interfaz inferior y recorte central. El formato 9:20 no garantiza compatibilidad universal. Si el generador no reproduce bien los nombres, conserve espacio para componerlos manualmente. Antes de publicar, compruebe derechos de uso y fidelidad a los activos auténticos; estos prompts no acreditan adopción oficial.
