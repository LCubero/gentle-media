Para cada imagen, abra **un** archivo `.md`, copie todo su texto y péguelo como prompt en el generador. Adjunte **solo** el archivo `assets/` indicado dentro de ese prompt, relativo a esta carpeta `v5/`; no adjunte las otras dos imágenes. Repita el proceso por separado para otro estilo o producto. No se incluyen imágenes generadas.

Los prompts reservan zonas libres para reloj e interfaz inferior y bordes prescindibles para recortes habituales 9:16, 19.5:9 y 20:9; compruebe cada vista previa en el dispositivo previsto, sin asumir compatibilidad universal. Antes de publicar, revise legibilidad, ortografía, integridad de la silueta y derechos de uso de las marcas candidatas; estos archivos no acreditan adopción oficial.
