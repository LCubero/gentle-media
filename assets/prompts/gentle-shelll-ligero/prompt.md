# Production prompt — Gentle Shell, 60 seconds

Act as a motion director, editor, technical fact-checker and sound designer. Produce a credible, restrained **Gentle Shell** film from the accompanying storyboard and source ledger. This kit specifies a film; it does **not** contain a rendered MP4. First deliver a shot/timing plan and a rights/claim check. Render only with an authorized production environment and cleared media; otherwise return the production-ready plan and disclose that no render occurred.

## Non-negotiable brief

- Duration **exactly 60.000 seconds at 30 fps (1,800 frames)**; use six half-open frame intervals: 0–150 (0–5 s), 150–450 (5–15 s), 450–780 (15–26 s), 780–1140 (26–38 s), 1140–1530 (38–51 s), 1530–1800 (51–60 s). No extra logo tail or blank frame.
- Two separately composed deliverables: **1920×1080 / 16:9** and **1080×1920 / 9:16**, both 30 fps. English on-screen titles in both. Provide English captions and an optional *alternative* neutral/professional Spanish subtitle track from the paired SRT drafts; never burn both languages on top of each other.
- Core story: the developer directs a Pi-specific coding-agent workspace; small work remains small, focused agents have a return path, and captured write/edit changes can be inspected. One parent remains responsible. Show mechanism through focus, task, capture and return, then name the value. Do not make optional integrations universal.
- Use `storyboard.md` for shot copy and timing, `claims-and-assets.md` for exact provenance, and four bundled authentic references for appearance. The authentic frames depict a particular pinned revision, **not a guarantee of present-day UI**. Avoid fictitious terminal commands, legible invented code/diffs, fabricated dashboards and fake screen recordings. Build abstract motion where real interaction footage is unavailable; identify abstractions in handoff.

Use near-black/charcoal and a restrained rose accent sampled visually from supplied official artwork, never an asserted brand hex specification. Compose grid-aligned transitions from cursor → parent frame → task → captured change → return → final lockup. Crop official imagery proportionally without relettering marks. In portrait, redesign the visual hierarchy: enlarged single pane, then details, rather than shrinking a desktop screenshot. Protect a conservative 10% graphic safe area; test subtitles against phone overlays. Prefer one large headline at a time and at least 2 seconds of uninterrupted reading for short headline cards; final brand card holds ≥3 seconds. Preserve contrast and avoid rapid flashes, flicker or illegible fine UI text.

## Accuracy gates

Use only the pinned Gentle Shell README and `docs/gentle-shell.md` for product statements until a producer deliberately verifies a newer release. Distinguish observed UI layout, source-described behavior and abstract dramatization. Changes captures successful write/edit tool operations in the current session and owned subagents; it is **not** an all-Git audit, and missing rows do not prove a clean worktree. Provider usage depends on supported accounts; do not promise it always appears. Memory is a separately installed optional companion; native receipt-driven review requires user choice and is not the central feature here. Do not promise that all agents run simultaneously, every host has identical UI, or review approval delivers code. Exclude unverifiable performance, customer, security and licensing claims. No read-only reference can authorize trademark or music use: clear intended distribution separately.

## Handoff and verification

Deliver: (1) claim/asset/rights ledger with source revision and unresolved permissions; (2) frame-numbered shot list with copy, transition and sound; (3) distinct horizontal and portrait layouts; (4) paired timed English/Spanish caption drafts and caption-safe review; (5) only **if actually rendered**, both playable masters plus codec, pixel dimensions, measured frame count/duration, frame rate, audio inspection and human watch-through results. If no render, explicitly say **no MP4 rendered; video export and synchronized final-film mix not verified**. The local, unpublished WAV drafts' durations and sample peaks were measured, but audible quality and sync in a rendered film have not been listened to or verified. Before publication, check legal rights to marks/images/music/voice and any attribution requirements; confirm current UI claims against the release being advertised. Review once with sound and once muted, at desktop and phone size. Confirm each beat starts on its specified frame, the last frame is 1799, subtitle last out-point is 00:01:00,000, and no title or subtitle is clipped. Record every substitution, omission, failed check or unresolved clearance; never claim verification from a storyboard alone.
