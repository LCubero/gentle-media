# Gentle Media

Recursos de trabajo para crear imágenes, animaciones y videos sobre Gentleman Programming y los proyectos Gentle-AI, gentle-shell y Engram. Este repositorio reúne investigación, guías editoriales, referencias visuales, prompts y ejemplos; no es una aplicación que deba instalarse.

## Por dónde empezar

1. Consulte el [contexto de los proyectos y los límites de las afirmaciones](assets/contexto/README.md) antes de redactar una pieza.
2. Elija un formato en la [guía de estilos y tamaños](research/media-styles-size-etc.md) y revise las [indicaciones para media animada](gentleman-guidelines/Alan-guidelines.md).
3. Explore la [biblioteca de prompts](assets/prompts/README.md) y adapte uno a su pieza. Compruebe las referencias y los derechos de las imágenes antes de publicarla.
