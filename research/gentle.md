# Ecosistema de **Gentleman Programming** — Frases clave y media prompts

- **“Memoria persistente para agentes IA”** – Engram añade “un cerebro” a tus agentes de codificación. Guarda decisiones y convenciones estructuradas para que tu IA recuerde el contexto del proyecto.  
- **“Entorno de ingeniería determinista”** – Gentle-AI convierte el agente que ya usas en un ingeniero disciplinado. El agente aprende, sigue un flujo de trabajo estructurado y prueba cada cambio.  
- **“Convierte tu agente IA en un ingeniero disciplinado”** – Gentle-AI aplica buenas prácticas (ODD, SDD, RDD, TDD) a agentes como Claude, Cursor, Codex, Pi… sin bloquearlos. Es “un binario único, sin bloqueo de agente”.  
- **“Desarrollo Orgánico Dirigido (ODD)”** – Flujo por defecto que mantiene los cambios pequeños y exploratorios. El agente lee código, explora el problema, luego implementa paso a paso con evidencia.  
- **“Desarrollo Dirigido por Especificaciones (SDD)”** – Modo bajo demanda: el agente diseña y verifica artefactos formales cuando la complejidad lo requiere. No es el flujo por defecto, sino una “rama” deliberada dentro de ODD.  
- **“Revisión basada en Recibos (RDD)”** – Cada cambio pasa revisión inmutable: la evidencia se ata a la versión exacta del código. Impide que una revisión se desvíe; cada commit lleva su prueba.  
- **“TDD estricto”** – Se captura primero la prueba que falla, luego el código para pasarla. Así el agente demuestra el comportamiento antes y después.  
- **“Código Limpio + Arquitectura Limpia”** – Filosofía central (Clean Code, Clean Architecture) presente en la comunidad. Gentleman Programming promueve “código limpio y metodologías ágiles” como base del oficio.  
- **“Persona Mentor – ‘Gentleman’”** – El agente puede hablar como un mentor riguroso pero amable. Explica el **porqué**, no solo el cómo, cuidando que el usuario entienda las decisiones.  

## Terminología y tecnologías clave

- **Agentes IA / LLMs**: Claude Code, OpenAI Codex, Cursor, OpenCode, VS Code Copilot, Gemini CLI, Qwen Code, Antigravity, Pi, Windsurf, Kiro IDE, etc.. Gentle-AI agrega memoria y flujos a estos agentes.  
- **Herramientas del stack**: Go, SQLite (+ FTS5), Node.js, TypeScript, Rust (Horizon), Git, Docker (no requerido en engel-AI). Interfaz CLI, API REST, TUI. Librerías: React, Angular, Astro, Svelte, Tailwind CSS (caso de estudio en LinkedIn).  
- **Memoria y Contexto**: Engram (SQLite local), sincronización Git opcional, MCP server. “Context7 MCP” para docs en vivo.  
- **Metodologías**: ODD (Organic Driven Development), SDD (Spec-Driven), RDD, TDD, Clean Agile, hexagonal, TDD, agile, pruebas, aceptación continua.  
- **Otros términos de marca**: Built-with Gentle-AI (logotipo “rosa”👆), “Gentle-AI™” y “Engram™” son trademark de Alan Buscaglia. Gentle Shell (Pi-native harness), Guardian Angel (revisión de código con IA).  
- **Hashtags / Comunidad**: #gentleai, #frontend, #react, #desarrollo, #opensource, #IA. Referencia a la **Discord/YouTube/Twitch** de Gentleman Programming como centro comunitario.
