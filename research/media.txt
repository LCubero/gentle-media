# 2. Ratios

| Ratio | Resolución base | Uso |
|---|---:|---|
| **16:9** | 1920×1080 | Desktop, videos, hero, YouTube |
| **9:16** | 1080×1920 | Mobile, Reels, Shorts, TikTok |
| **1:1** | 1080×1080 | Social |
| **4:5** | 1080×1350 | Feed vertical |
| **2:1** | 1280×640 | GitHub Social Preview |

### Regla rápida

```text
Desktop → 16:9
Mobile  → 9:16
GitHub  → 2:1
Social  → 1:1 / 4:5
```

# 3. Qué formato usar

### PNG

Usar para:

- screenshots
- UI
- dashboards
- texto
- logos
- thumbnails
- transparencia

**Default para screenshots.**

### JPG

Usar para:

- fotografías
- backgrounds complejos

Evitar para UI con texto pequeño.

### WebP

Usar para:

- portfolio
- websites
- documentación web

Muy buena relación calidad/peso.

### GIF

Usar para:

- demos cortas
- README
- loops simples

Preset:

```text
5–15 segundos
10–15 FPS
800–1200 px ancho
loop
sin audio
```

Si pesa demasiado → **MP4**.

### MP4

Default:

```text
H.264
AAC
30 FPS
CRF 20–23
faststart
```

# 7. Banner Master

No diseñes cada tamaño desde cero.

Crea un sistema adaptable:

```text
MASTER
  │
  ├── 16:9
  ├── 9:16
  ├── 1:1
  ├── 4:5
  └── 2:1
```

Mantén como componentes separados:

```text
background
logo
project-name
tagline
UI
feature-copy
decorations
```

Así puedes reposicionarlos según ratio.

**No hagas solamente crop.**

---

# 8. Safe Areas

Mantén lo importante lejos de los bordes:

- logo
- título
- tagline
- CTA
- feature principal

Especialmente en:

```text
9:16
banners
social covers
video vertical
```

Las plataformas pueden colocar UI encima o aplicar crops diferentes.

Si una plataforma no publica una safe area oficial, usa márgenes conservadores en vez de asumir números exactos.

# 11. Thumbnail / primer frame

Estos conceptos son diferentes:

```text
FIRST FRAME
≠
THUMBNAIL
≠
POSTER
≠
SOCIAL PREVIEW
```

Pero pueden compartir diseño.

## Primer frame

Debe verse bien por sí solo.

Evita:

- transición empezada
- cursor raro
- UI cargando
- pantalla vacía
- elementos cortados

Ideal:

```text
PROJECT
Short tagline

[ UI lista ]

→ comienza demo
```

En GIF, además piensa:

```text
último frame
      ↓
primer frame
```

El loop debe sentirse natural.

# 12. Demo

Guion simple:

```text
ESTADO INICIAL
      ↓
ACCIÓN
      ↓
RESULTADO
      ↓
ACCIÓN
      ↓
RESULTADO FINAL
```

Elimina:

- esperas
- errores
- clicks incorrectos
- búsqueda del botón
- movimientos inútiles
- loading innecesario

# 13. Cursor

Cursor:

- suave
- directo
- intencional
- pausa breve antes del click
- fuera del foco después

Evita:

```text
círculos
zig-zag
temblores
movimientos gigantes
cursor encima del resultado
```

---

# 14. Ritmo

Para promoción:

```text
acción → resultado
acción → resultado
acción → resultado
```

No:

```text
acción
↓
2 segundos esperando
↓
scroll
↓
esperar
↓
acción
```

Puedes cortar tiempos muertos.

# 18. FFmpeg — MP4

```bash
ffmpeg -i input.mov \
  -c:v libx264 \
  -crf 22 \
  -preset slow \
  -c:a aac \
  -b:a 128k \
  -movflags +faststart \
  output.mp4
```

Preset general:

```text
H.264
CRF 20–23
30 FPS
AAC 128k
faststart
```

---

# 19. GIF optimizado

### Crear palette

```bash
ffmpeg -i demo.mp4 \
  -vf "fps=12,scale=1000:-1:flags=lanczos,palettegen" \
  palette.png
```

### Crear GIF

```bash
ffmpeg -i demo.mp4 -i palette.png \
  -filter_complex \
  "fps=12,scale=1000:-1:flags=lanczos[x];[x][1:v]paletteuse" \
  demo.gif
```

Pipeline:

```text
VIDEO
 ↓
CROP
 ↓
FPS
 ↓
RESIZE
 ↓
PALETTE
 ↓
GIF
 ↓
OPTIMIZE
```

# 23. Workflow

## Paso 1 — Preparar

```text
UI limpia
datos listos
viewport
cursor
scroll
notificaciones OFF
```

## Paso 2 — Capturar masters

```text
Desktop → 16:9
Mobile  → 9:16
```

## Paso 3 — Derivar

```text
MASTER
  │
  ├── screenshots
  ├── MP4
  ├── GIF
  ├── thumbnails
  ├── banners
  ├── social preview
  ├── 1:1
  └── 4:5
```

## Paso 4 — Optimizar

```text
PNG → compress
GIF → palette + optimize
MP4 → H.264 + CRF
```

## Paso 5 — Publicar

```text
README
GitHub Social Preview
Portfolio
Social
Video platforms
```

# 24. Regla de oro

Cada asset responde **UNA pregunta**:

### ¿Qué es?

```text
Brand Banner
```

### ¿Cómo se ve?

```text
Screenshot / Product Banner
```

### ¿Cómo funciona?

```text
GIF / MP4
```

### ¿Qué feature importa?

```text
Feature Banner
```

No intentes explicar todo en una sola pieza.
