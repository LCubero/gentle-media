## 4. Asset Checklist & Naming

Create dedicated assets for all platforms. Use project name or role in filenames. Base everything on two masters: **16:9 desktop (1920×1080)** and **9:16 mobile (1080×1920)**.

| Asset           | Ratio/Size      | Example File Name (Gentle-AI)    | Usage               |
|----------------|---------------|---------------------------------|---------------------|
| **GitHub Social Preview** | 2:1 (1280×640)   | `gentle-ai-github-preview-1280x640.png`  | GitHub repo social image.   |
| **Thumbnail (H)** | 16:9 (1920×1080) | `gentle-ai-thumb-16x9.png`         | YouTube thumbnail, X banner, general use.   |
| **Thumbnail (V)** | 9:16 (1080×1920)  | `gentle-ai-thumb-9x16.png`          | Reels, Shorts, Stories.           |
| **Banner – Brand** | H 16:9 (1920×1080)   | `gentle-ai-banner-brand-1920x1080.png` | Logo/title overlay (for LinkedIn, FB covers, keynote slides).  |
| **Banner – Product** | H 16:9 (1920×1080) | `gentle-ai-banner-product-1920x1080.png` | Screenshot or mockup of UI with tagline.  |
| **Banner – Feature** | H 16:9 (1920×1080) | `gentle-ai-banner-feature-1920x1080.png` | Highlight one feature (e.g. “ODD workflow”).  |
| **Square Post**  | 1:1 (1080×1080)   | `gentle-ai-social-square-1080.png`    | Instagram/Twitter feed posts.     |
| **Portrait Post**| 4:5 (1080×1350)   | `gentle-ai-social-portrait-1080x1350.png` | Instagram feed portrait.         |
| **Demo Video (H)**| 16:9 (1920×1080)  | `gentle-ai-demo-1080p.mp4`           | YouTube, Twitter, LinkedIn videos.     |
| **Demo Video (V)**| 9:16 (1080×1920)  | `gentle-ai-demo-9x16.mp4`            | Reels/Shorts/TikTok videos.      |
| **GIF (Readme)** | ~800–1200 px width | `gentle-ai-demo-readme.gif`          | GitHub README animation.          |
| **Screenshots (Desktop)** | H 16:9 (1920×1080) | `gentle-ai-screenshot-home-desktop.png` | In README, blog, docs.         |
| **Screenshots (Mobile)** | V 9:16 (1080×1920) | `gentle-ai-screenshot-home-mobile.png`  | To illustrate mobile UI.      |

- **Safe Areas:** Keep logos/text away from edges (especially on vertical assets where UI chrome might overlay). The user interface content should not be obscured by text or platform UI.  
- **Naming:** Use descriptive names with project and dimensions. E.g. `engram-electric-config-1920x1080.png`. Avoid generic names.  
- **Formats:** Use **PNG** for screenshots, banners (lossless, sharp UI). Use **JPG** only for complex backgrounds (e.g. scenic) if needed. **GIF** for short loops (5–15s, 10–15fps, ~800–1200px wide, no audio). **MP4 (H.264)** for videos (30fps, AAC audio, faststart).

## 8. Media Workflow (Diagram)

```mermaid
flowchart LR
    A[Design/Code Completed] --> B{Prepare Assets}
    B --> C(Desktop Master: 16x9)
    B --> D(Mobile Master: 9x16)
    C --> E{Export}
    D --> F{Export}
    E --> E1(Screenshot 16x9 PNG)
    E --> E2(Video 16x9 MP4)
    E --> E3(GIF from video 800px)
    E --> E4(Thumbnail 16x9 PNG)
    F --> F1(Screenshot 9x16 PNG)
    F --> F2(Video 9x16 MP4)
    F --> F3(GIF 9x16 if needed)
    F --> F4(Thumbnail 9x16 PNG)
    E1 --> G[Optimize PNG/JPG]
    E2 --> H[FFmpeg encode (H.264, CRF22)]
    E3 --> I[GIF palette -> optimize]
    E4 & F4 --> J[Add Overlay Text, Logos]
    J --> K[Asset Completed]
    G & H & I & K --> K
```
Steps:
1. *Clean base capture/code* (UI set up, data ready). 
2. Produce two **master recordings/screenshots**: 1920×1080 and 1080×1920.
3. From these masters, export screenshots, videos (MP4), GIFs (via palette optimization), thumbnails.
4. Add overlays or branding as needed.  
5. Compress (PNGCrush, gif2/webp, etc) and store per structure. 

## 9. Export Presets & Tools

- **FFmpeg (MP4):** `ffmpeg -i input.mov -vf "scale=1920:-2" -c:v libx264 -crf 22 -preset slow -pix_fmt yuv420p -movflags +faststart -c:a aac -b:a 128k output.mp4` (adjust scale for vertical: `1080:-2`).  
- **FFmpeg (GIF):**  
  ```
  ffmpeg -i demo.mp4 -vf "fps=12,scale=800:-1:flags=lanczos,palettegen" palette.png
  ffmpeg -i demo.mp4 -i palette.png -filter_complex "fps=12,scale=800:-1:flags=lanczos[x];[x][1:v]paletteuse" demo.gif
  ```  
  Optimize further with `gifsicle` or similar. Keep <10 FPS and moderate length.  
- **Compression:** PNGs can be run through [pngquant](https://pngquant.org/) or [ImageOptim]. JPGs at quality ~85%.  
- **Naming Convention Script:** You can use consistent naming with tools or manually rename after export (see checklist above).
